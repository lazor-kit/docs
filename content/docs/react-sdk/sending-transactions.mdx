---
title: Sending transactions
description: Prepare, approve and confirm Protocol transactions with the React adapter.
---

Build the intended Solana instructions and call `signAndSendTransaction` from the installed
adapter. Check that the provider, wallet and paymaster serve the same Protocol
deployment. Use the vault PDA for asset transfers.

## Confirm the result

Retain the transaction signature and check its confirmation with the selected RPC.
When a relay response is lost, check the original signature before preparing a new
payment. Review the installed adapter's callbacks and error types for your version.

## Transaction format and deferred execution

Use a transaction format supported by the RPC, adapter and paymaster. A transaction
that exceeds its wire limit needs a compatible format or a smaller action. Check
size before asking the user to approve.

For an action that must be approved before it is submitted, use the Protocol SDK's
`prepareAuthorize`, `finalizeAuthorize` and `executeDeferredFromPayload`.
Respect the expiry slot and retain the authorization's payload.

See [Protocol signing](/web3js-v1/passkey-signing), [Paymaster](/concepts/paymaster)
and [Protocol errors](/errors).
