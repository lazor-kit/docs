---
title: Upgrade an adapter
description: Check Protocol support before updating a wallet adapter.
---

Pin the installed `@lazorkit/wallet` version. Before updating, check that the new version
recognizes the same Protocol program ID, reconnects to an existing wallet, and can
sign the flows you use with the selected paymaster.

Test with wallets your app created on an earlier release. Record the expected wallet
PDA and vault PDA before the upgrade, then reconnect and compare them. Retest the
session and deferred flows if your app uses them.

See [Protocol upgrades](/v1-to-v2) and the [release history](/changelog).
