---
title: React SDK with Protocol v1
description: Configure the released adapter for a Protocol v1 integration.
---

Use [Networks & SDK compatibility](/networks) to select a version of `@lazorkit/wallet`
that supports your Protocol wallet and the flows your app needs. As the published
adapter versions can differ in wallet creation and wallet detection, test reconnection
to an existing wallet before enabling the integration.

Configure your app's RPC URL and `paymasterConfig` for the same cluster. Use the passkey
portal matching the credential's relying-party domain. Keep the established wallet PDA
for program calls and display the separate vault PDA as the receive address.

For a new direct integration on Protocol v1, use the
[published Protocol SDK setup](/web3js-v1/getting-started).
