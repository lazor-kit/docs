---
title: React
description: Reconnect existing Protocol wallets with the React adapter.
---

Use `@lazorkit/wallet` to reconnect a wallet that your app already created on Protocol v1. The adapter opens the passkey portal and submits the approved transaction through your paymaster.

- [Get started](/react-sdk/getting-started)
- [Send a transaction](/react-sdk/sending-transactions)
- [Confirm a returning wallet](/react-sdk/wallet-confirmation)
- [Upgrade an integration](/react-sdk/upgrading)

For creating a new Protocol wallet, use the [TypeScript quickstart](/web3js-v1/getting-started).
