---
title: Wallet Standard
description: Add existing Protocol wallets to your Solana wallet picker.
---

If your React app already uses Solana Wallet Adapter, register LazorKit so returning Protocol users can select it. Start with the [React quickstart](/react-sdk/getting-started) for the package pin.

## Register in the browser

Call `registerLazorkitWallet` once on the client, using the RPC and paymaster for the existing wallets. The portal must match the passkey's registered origin.

```ts
import { registerLazorkitWallet } from '@lazorkit/wallet';

export function registerProtocolWallet(portalUrl: string, protocolPaymasterUrl: string) {
  const paymaster = { paymasterUrl: protocolPaymasterUrl };

  registerLazorkitWallet({
    cluster: 'mainnet',
    rpcUrl: 'https://api.mainnet-beta.solana.com',
    portalUrl,
    paymasterConfig: paymaster,
    v1PaymasterConfig: paymaster,
  });
}
```

## Send and receive

- The connected `publicKey` is the vault. Use it as the receive address and as the source of a transfer.
- Call Wallet Adapter's `sendTransaction` to approve and send the transaction. The adapter handles relay submission and returns a signature after confirmation.
- Use the [React adapter](/react-sdk) for session keys, deferred execution, or authority management.

If the wallet picker asks which wallet to use, follow [Confirm a returning wallet](/react-sdk/wallet-confirmation).

## Message signing

LazorKit returns a WebAuthn P-256 proof as UTF-8 JSON. Verify the expected message with `verifyWalletMessage` on your server, using the Protocol wallet PDA, credential ID, and registered relying-party ID. Resolve the authority from chain for verification.
