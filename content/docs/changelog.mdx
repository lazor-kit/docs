## Protocol SDK 0.3.2

The published SDK builds instructions for existing Protocol wallets on Mainnet and Devnet. This release removes the Node.js `crypto` dependency from the SDK.

- [Version 0.3.2 on npm](https://www.npmjs.com/package/@lazorkit/sdk-legacy/v/0.3.2)
- [Protocol SDK reference](https://github.com/lazor-kit/lazorkit-protocol/tree/sdk-legacy-v0.3.2/sdk/sdk-legacy)

## Updating an existing integration

Before updating, test with a wallet your app already created. Check its wallet and vault addresses, reconnect with the same passkey, and confirm a transaction through your paymaster.

See the [React checklist](/react-sdk/upgrading) or the [React Native checklist](/react-native-sdk/upgrading).
