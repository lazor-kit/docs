The public mainnet client is `@lazorkit/sdk-legacy@0.3.2`. Use the exact version
when setting up an integration. Keep the program ID and paymaster pointed at
the same cluster. Use a Protocol-compatible paymaster for existing wallets.

The React and React Native packages publish their own release notes. Check
the supported program IDs before adopting a new version.

Use the **vault PDA** as the wallet's receive address. The **wallet PDA**
stores the protocol's internal wallet record. Always derive addresses with
the program ID for your selected cluster.
