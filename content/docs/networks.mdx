## Packages

Protocol v1 is the on-chain program. The package numbers below identify the SDK release for each environment.

| What you're building | Install this package | Use it for |
| --- | --- | --- |
| A new Protocol integration | `@lazorkit/sdk-legacy@0.3.2` | Create wallets and build transactions directly |
| A React app with Protocol wallets | `@lazorkit/wallet@3.4.1` | Reconnect and transact with existing wallets |
| A React Native app with Protocol wallets | `@lazorkit/wallet-mobile-adapter@2.4.0` | Reconnect and transact with existing wallets |

These examples use `@solana/web3.js@^1.99.0`. Pin the LazorKit package version in your app. The [TypeScript quickstart](/web3js-v1/getting-started) covers creating a new Protocol wallet.
