---
title: React Native
description: Reconnect existing Protocol wallets with the React Native adapter.
---

Use `@lazorkit/wallet-mobile-adapter` to reconnect a wallet that your app already created on Protocol v1. The adapter opens the passkey portal and submits the approved transaction through your paymaster.

- [Get started](/react-native-sdk/getting-started)
- [Send a transaction](/react-native-sdk/sending-transactions)
- [Confirm a returning wallet](/react-native-sdk/wallet-confirmation)
- [Upgrade an integration](/react-native-sdk/upgrading)

For creating a new Protocol wallet, use the [TypeScript quickstart](/web3js-v1/getting-started).
