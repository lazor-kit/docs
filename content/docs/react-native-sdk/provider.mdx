---
title: Provider configuration
description: Connect an adapter to the selected Protocol deployment.
---

Use the provider options from your installed `@lazorkit/wallet-mobile-adapter` version.
Set an explicit RPC URL, cluster, portal origin and `configPaymaster` that support the same
Protocol deployment. If that version uses a separate Protocol v1 relayer option,
configure it according to its versioned API. On React Native and Expo also register
the app's callback scheme with the signing portal.

Keep privileged paymaster credentials on your backend. Give client applications
a scoped endpoint that enforces your application's sponsorship policy.

See [Getting started](/react-native-sdk/getting-started) and [Networks](/networks).
