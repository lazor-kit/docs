---
title: Provider options
description: Configure the React Native provider for Protocol wallets.
---

The [React Native quickstart](/react-native-sdk/getting-started#configure-the-provider) shows how to set up `LazorKitProvider`.

| Option | Value |
| --- | --- |
| `rpcUrl` and `cluster` | The RPC and cluster of the existing wallet |
| `portalUrl` | The portal origin used to create the passkey |
| `v1ConfigPaymaster` | The endpoint that sponsors this wallet's Protocol transactions |

Keep privileged paymaster credentials on your backend. Give the client an endpoint with your application's sponsorship rules.
