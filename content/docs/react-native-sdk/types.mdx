---
title: Adapter types
description: Read the API types for the installed SDK version.
---

Use the types shipped by `@lazorkit/wallet-mobile-adapter` for the installed release.

```ts
import type { useWallet } from '@lazorkit/wallet-mobile-adapter';

type WalletHook = ReturnType<typeof useWallet>;
```

A wallet PDA identifies the Protocol account. A vault PDA holds funds. Read the
adapter's vault field for a receive address and save the wallet PDA for program calls.
For raw instructions and on-chain types, use [Protocol SDK types](/web3js-v1/types).
