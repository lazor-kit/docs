---
title: Send a transaction
description: Confirm a passkey-approved Protocol transaction from React Native.
---

After reconnecting the expected Protocol wallet, build the action's Solana instructions. Use the vault as the source for a transfer.

```tsx
import { useWallet } from '@lazorkit/wallet-mobile-adapter';
import type { TransactionInstruction } from '@solana/web3.js';

export function useSendProtocolTransaction(redirectUrl: string) {
  const { protocolVersion, signAndSendTransaction } = useWallet();

  return async (instructions: TransactionInstruction[]) => {
    if (protocolVersion !== 1) throw new Error('Connect your Protocol wallet first.');
    return signAndSendTransaction({ instructions }, { redirectUrl });
  };
}
```

Pass the registered callback from the [mobile quickstart](/react-native-sdk/getting-started#reconnect-and-send). Call the hook's returned function from a user action after showing what they will approve. Save the returned signature. If relay submission is uncertain, check that signature before requesting a second approval.

For separate approval and submission, see [deferred execution](/web3js-v1/passkey-signing#deferred-execution). For fee sponsorship, see [Paymaster](/concepts/paymaster).
