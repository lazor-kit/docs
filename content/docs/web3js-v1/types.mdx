---
title: Protocol SDK types
description: Types exported by the published Protocol SDK.
---

Import instruction builders, signer helpers and account types from
`@lazorkit/sdk-legacy`. Use `PublicKey` and `TransactionInstruction` from
`@solana/web3.js` v1. Let TypeScript infer the parameters and results of the installed
`LazorKitClient` to keep integrations aligned with that version.

```ts
import { LazorKitClient } from '@lazorkit/sdk-legacy';

type ExecuteParams = Parameters<LazorKitClient['execute']>[0];
type CreateSessionParams = Parameters<LazorKitClient['createSession']>[0];
type DeferredResult = Awaited<ReturnType<LazorKitClient['prepareAuthorize']>>;
```

A session expiry is an absolute slot. Session actions are serialized by `serializeActions`.
Authority roles are `ROLE_OWNER`, `ROLE_ADMIN` and `ROLE_SPENDER`. Use explicit
[network constants](/networks) when deriving wallet, vault, authority and session PDAs.

See the [Published SDK source](https://github.com/lazor-kit/lazorkit-protocol/tree/sdk-legacy-v0.3.2/sdk/sdk-legacy).
