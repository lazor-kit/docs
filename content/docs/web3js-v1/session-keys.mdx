---
title: Protocol session keys
description: Create and revoke a time-limited Protocol session.
---

Use `createSession` to register a key with an absolute expiry slot. Keep the
session key in your application's secure key storage and set a short lifetime.
Use `revokeSession` from a wallet Owner or Admin to close the session.
For the policy fields and wire format supported by the current deployment,
use the Protocol SDK reference for your installed version.

[Protocol SDK 0.3.2 reference](https://github.com/lazor-kit/lazorkit-protocol/tree/sdk-legacy-v0.3.2/sdk/sdk-legacy)
