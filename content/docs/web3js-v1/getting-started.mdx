---
title: Getting started with Protocol
description: Install the current client and select a Protocol deployment.
---

```bash
npm install @lazorkit/sdk-legacy@0.3.2 @solana/web3.js
```

```ts
import { Connection } from '@solana/web3.js';
import { LazorKitClient, PROGRAM_ID_DEVNET } from '@lazorkit/sdk-legacy';

const connection = new Connection('https://api.devnet.solana.com', 'confirmed');
const client = new LazorKitClient(connection, PROGRAM_ID_DEVNET);
```

Choose a paymaster that supports the same deployment. Display the vault PDA
as the receive address. Keep the wallet PDA for program calls.

[Protocol SDK 0.3.2 reference](https://github.com/lazor-kit/lazorkit-protocol/tree/release/sdk-legacy-0.3.2/sdk/sdk-legacy)
