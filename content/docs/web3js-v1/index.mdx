---
title: Protocol SDK
description: Use the published LazorKit Protocol SDK with @solana/web3.js v1.
---

Install the public Protocol client for applications that build instructions directly.

```bash
npm install @lazorkit/sdk-legacy@0.3.2 @solana/web3.js@^1.95.0
```

| Area | SDK 0.3.2 methods |
| --- | --- |
| Wallet and authority | `createWallet`, `addAuthority`, `removeAuthority`, `transferOwnership` |
| Execute | `execute`, `transferSol`, `prepareExecute`, `finalizeExecute` |
| Sessions | `createSession`, `prepareCreateSession`, `finalizeCreateSession`, `revokeSession` |
| Deferred | `prepareAuthorize`, `finalizeAuthorize`, `executeDeferredFromPayload`, `reclaimDeferred` |
| Accounts | `findWallet`, `findVault`, `findAuthority`, `findSession` |

For a returning wallet, keep the wallet PDA your app established during onboarding and
verify the wallet and authority against the selected Protocol program. A credential ID
lookup alone does not prove ownership of a wallet. Use the vault PDA as the receive address.

See [Getting started](/web3js-v1/getting-started), [Networks](/networks) and the
[published SDK reference](https://github.com/lazor-kit/lazorkit-protocol/tree/release/sdk-legacy-0.3.2/sdk/sdk-legacy).
