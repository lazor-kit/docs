Use `@lazorkit/sdk-legacy` to create a Protocol wallet, submit an action, or manage session keys.

- [Getting started](/web3js-v1/getting-started) sets up a Devnet client and creates a wallet.
- [Passkey signing](/web3js-v1/passkey-signing) covers direct and deferred execution.
- [Session keys](/web3js-v1/session-keys) covers delegated signing.
- [SDK types](/web3js-v1/types) shows how to use the TypeScript API.

[Networks and versions](/networks) lists the package pin and both program IDs.
