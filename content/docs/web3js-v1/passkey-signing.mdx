---
title: Protocol passkey signing
description: Prepare and finalize a Protocol passkey transaction.
---

For an immediate action, use `prepareExecute`, sign the returned challenge
with the wallet's existing passkey, and pass the assertion to `finalizeExecute`.
Submit the returned instructions in order so the verification instruction
immediately precedes `Execute`. Use `prepareAuthorize` and
`executeDeferredFromPayload` when approval and execution happen separately.
