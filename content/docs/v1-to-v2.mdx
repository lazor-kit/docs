**LazorKit Protocol** is the supported production smart-wallet program.
**LazorKit Enterprise** is a separate program with its own addresses, deployment
approvals, and integration path. Enterprise is available on devnet.

Existing Protocol wallets continue to use Protocol. There is no announced requirement
for users to move funds or create an Enterprise wallet. Older SDKs and release notes
may refer to Protocol as `v1` and Enterprise as `v2`, including in method names,
configuration, and error classes.

## Integrating a wallet

- For Protocol, select the correct cluster and use a Protocol-compatible client or
  the Protocol paymaster configuration for your UI SDK.
- For Enterprise, configure the Enterprise devnet program and a matching client and
  paymaster.
- Use the vault address returned by your SDK for the selected product. A wallet on
  one program has its own address and balances.

See [Networks & SDK compatibility](/networks) for the full compatibility matrix.
