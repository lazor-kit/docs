# SDK — web3.js v2

> _This SDK is in development. Content will be added when available._

The web3.js v2 SDK will provide the same LazorKit contract interaction capabilities as [`@lazorkit/sdk-legacy`](/web3js-v1) but built on `@solana/web3.js` v2 — the new Solana web3 library with tree-shakeable modules, functional APIs, and improved TypeScript types.

For now, use the [web3.js v1 SDK](/web3js-v1).
