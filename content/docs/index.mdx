LazorKit is an execution layer for Solana. It handles **passkey authentication**, **session key delegation**, **gas sponsorship**, and **on-chain permission enforcement** — so your app or agent can go from user intent to on-chain action without the usual friction.

<Callout type="info" title="New here?">
  Start with the [Protocol Overview](/protocol) to understand how the system works end-to-end, then pick the SDK that fits your stack.
</Callout>

<Callout type="warn" title="Upcoming changes for integrators">
  The LazorKit portal is being updated, and devnet now measures session time in seconds.
  What changes for your SDK version, and what to do before then:
  [Upcoming changes for integrators](/upgrade-notice).
</Callout>

<Callout type="warn" title="Where things stand (2026-10-11)">
  Mainnet runs **protocol v1**. Protocol v2 — what the current SDK releases speak — is
  live on **devnet**; the v2 mainnet program is not deployed yet. Existing v1 wallets keep
  working through the current React and React Native SDKs. Devnet's v2 now measures
  session time in seconds: creating a session there needs `@lazorkit/wallet` 4.0 or
  `@lazorkit/wallet-mobile-adapter` 3.0, pre-releases on the npm `next` tag
  ([Migrating to 4.0](/react-sdk/migrating-to-4)). Program ids, package versions and what
  works where: [Networks & versions](/networks).
</Callout>

## Which package do I use?

| You are building | Package | Install | Version |
| ---------------- | ------- | ------- | ------- |
| A **React** web app | [`@lazorkit/wallet`](/react-sdk) | `npm i @lazorkit/wallet` | 3.4.1 (`latest`). 4.0.0-next.1 on `@next`, which creating a session on devnet needs |
| A **React Native** or Expo app | [`@lazorkit/wallet-mobile-adapter`](/react-native-sdk) | `npm i @lazorkit/wallet-mobile-adapter` | 2.4.0 (`latest`). 3.0.0-next.1 on `@next`, which creating a session on devnet needs |
| Program-level code on **`@solana/web3.js` v1**: your own UI, a backend, a relayer, an agent | [`@lazorkit/sdk-legacy`](/web3js-v1) | `npm i @lazorkit/sdk-legacy@next` | 2.1.0, protocol v2. Without `@next` you get `latest`, 0.3.2, the protocol v1 line |
| The same on **`@solana/kit`** (web3.js v2) | [`@lazorkit/sdk`](/web3js-v2) | `npm i @lazorkit/sdk @solana/kit` | 1.0.0-rc.8, release candidate, protocol v2 only |

The two UI SDKs handle the portal, the paymaster and confirmation for you, and install
`@lazorkit/sdk-legacy` themselves. Peer dependencies are in each Getting Started. Which
network each version works on: [Networks & versions](/networks).
